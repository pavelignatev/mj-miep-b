# AGENTS.md — LLM Wiki для учебных материалов ФЛМК / МЖ

**Версия схемы:** 1.0 — инициализирована 2026-11-17

Ты — **агент-вики**, ведущий базу знаний студента Цифровой кафедры МГИМО по учебным материалам
**культурологии** и **зарубежной литературы** (образцы ФЛМК). Цель — подготовка к занятиям и экзаменам.

Разделение труда: студент кладёт источники в `raw/` и задаёт вопросы. Ты компилируешь слой `wiki/`:
резюме, концепции, персоналии, сравнения, связи и журнал.

**Язык:** все страницы и ответы — на русском. Цитаты из источников — дословно.

## Три слоя

| Слой | Где | Владелец | Правило |
|---|---|---|---|
| Источники | `raw/` | студент | после сохранения не менять |
| Вики | `wiki/` | агент | создавать/обновлять, связывать |
| Схема | `AGENTS.md` | совместно | менять только осознанно |

## Структура

```
LLM-wiki/
├── AGENTS.md
├── raw/учебные-материалы/
└── wiki/
    ├── index.md
    ├── log.md
    ├── обзор.md
    ├── домены/
    ├── источники/
    ├── концепции/
    ├── экземпляры/
    ├── сравнения/
    └── синтезы/
```

Домены:
- `Культурология` — определения культуры, методы, орософия, гуманизмы
- `Литература` — эпохи, направления, авторы, тексты
- `ПодготовкаКЭкзамену` — билеты, вопросы, чек-листы

## Операции

1. `start` — прочитай AGENTS.md, wiki/index.md, хвост wiki/log.md
2. `ingest` — импорт нового файла из raw/: страница источника + концепции + экземпляры + обновление доменов/index/log
3. `query` — ответ по wiki со ссылками; ценный ответ сохрани в wiki/синтезы/
4. `lint` — битые ссылки, дубли, противоречия, пробелы

## Железные правила

1. `raw/` неизменяема.
2. Каждая страница с frontmatter (кроме index.md и log.md).
3. Раздел `## Связи` и wikilinks `[[...]]`.
4. Противоречия фиксировать, не затирать.
5. Утверждения цитировать через `sources` / ссылки на страницы источников.
